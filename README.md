# Runes & Ramparts (R&R)

Браузерная фэнтезийная Tower Defense без Godot, серверной зависимости и монетизации.
Первая играбельная сборка v0.1.0: «Лесной рубеж».

- Свободное строительство вне дороги и препятствий, шесть башен, три уровня и две специализации.
- Семь типов противников, включая босса Каменного короля; 12 волн.
- Пиксельная графика, оригинальные процедурно нарисованные спрайты с покадровой анимацией, частицы, снаряды, индикаторы урона и статусов.
- Оригинальная синтезированная чиптюн-музыка (Web Audio) и звуковые эффекты с независимыми переключателями. Звук запускается после взаимодействия с браузером.
- Пауза, скорости ×1/×2/×4, приоритеты целей, продажа, разведка волн, полноэкранный режим.
- Локальный рейтинг, автосохранение незавершённой игры (IndexedDB, резерв localStorage), импорт/экспорт JSON. При восстановлении активной волны игра на паузе.
- TypeScript, PixiJS, Vite; игровая симуляция отделена от графики.

## Запуск

Node.js 22+.

    npm ci
    npm run dev

Или Docker Compose:

    docker compose up -d --build

Откройте http://localhost:8080 для Docker; Vite выведет собственный адрес.

## Проверки

    npm test
    npm run build

## Управление

Выберите башню в нижней панели или клавишами 1–6, затем свободное место на карте.
Клик по построенной башне — улучшение, выбор цели или продажа. ESC или ПКМ — отмена выбора. Пробел — пауза.
Строить можно и во время волны. Все данные сохраняются в текущем браузере и origin.
