# Runes & Ramparts (R&R)

[![Угостить разработчика кофе / Buy me a coffee](https://img.shields.io/badge/Support-Buy%20me%20a%20coffee-7055a5?style=flat-square&logo=buymeacoffee&logoColor=white)](https://mirv.top/support/)

Браузерная фэнтезийная Tower Defense без Godot, серверной зависимости и монетизации.
Текущая версия v0.6.0: кампания из пяти рубежей, свет, звук и читаемые боевые построения.

- Свободное строительство вне дороги и препятствий, восемь башен, пять уровней и две специализации на третьем уровне.
- 15 типов противников, включая четыре вида боссов; 81 волна на пяти картах.
- Пиксельная графика, 64 варианта башен с разными силуэтами, отдельные эффекты оружия, оригинальные спрайты противников с покадровой анимацией, частицы, снаряды, индикаторы урона и статусов.
- Семь встроенных MP3-композиций и звуковые эффекты с независимыми регуляторами громкости. Звук запускается после взаимодействия с браузером.
- Пауза, скорости ×1/×2/×4, приоритеты целей, продажа, разведка волн, полноэкранный режим.
- Локальный рейтинг, автосохранение незавершённой игры (IndexedDB, резерв localStorage), импорт/экспорт JSON. При восстановлении активной волны игра на паузе.
- TypeScript, PixiJS, Vite; игровая симуляция отделена от графики.

## Запуск

Node.js 22+.

    npm ci
    npm run dev

Или Docker Compose:

    docker compose up -d --build

Откройте http://localhost:8080 для Docker; Vite выведет собственный адрес.

## Проверки

    npm test
    npm run build

## Управление

Выберите башню в нижней панели или клавишами 1–6, затем свободное место на карте.
Клик по построенной башне — улучшение, выбор цели или продажа. ESC или ПКМ — отмена выбора. Пробел — пауза.
Строить можно и во время волны. Все данные сохраняются в текущем браузере и origin.

## Изменения 0.2.0

Ветки башен обладают отдельными механиками. Уровни 4–5 продолжают выбранную ветку. Составные волны перемешиваются, поздние враги прочнее, боссы устойчивее к замедлению. Старые сохранения читаются без сброса, но действуют новые правила баланса.

## Кампания 0.3.0

Пять карт (12/15/16/18/20 волн), последовательное открытие, звёзды за победы
(1–7 жизней: 1 звезда, 8–15: 2, 16–20: 3), по одному очку развития за звезду.
Рекорды по картам. Старые победы засчитываются за лесной рубеж.
Глобальные улучшения применяются при начале нового боя.
Казармы, молнии, три активных заклинания; ранний вызов следующей волны
после выхода всех врагов текущей волны приносит золото, но волны перекрываются.
## Свет и звук 0.4.0

- Три полосы движения и дистанция между врагами: замедление больше не складывает противников в одну точку. Замороженные и отравленные враги сохраняют собственные цвета; состояния отмечены отдельно. Анимация ходьбы зависит от движения.
- Аддитивные цветные источники света, вспышки попаданий, дым, искры, ударные волны, ограниченная встряска камеры. Эффекты работают по реальному времени даже при скорости ×4. Координаты указателя преобразуются обратной матрицей камеры.
- Упрощённый режим графики отключает свечение, вспышки и встряску; автоматически выбирается при системной настройке reduced motion, если пользователь не переопределил режим.
- Музыкальное сопровождение меню, пяти биомов и боссов.
- Сохранения совместимы с предыдущими версиями. Скорректировано масштабирование здоровья на Пепельной пустоши.

## Саундтрек 0.6.0

Встроенные MP3 из предоставленных автором композиций, без пользовательского проигрывателя.
Музыка меняется автоматически, с плавным переходом и выравниванием громкости.
На экране подготовки и в бою звучит тема текущей карты; при появлении босса —
Final Showdown, после его гибели — снова тема карты. В меню и на экране итогов —
Realm of Legend. Композиции повторяются, звук запускается после первого действия
пользователя. Два регулятора громкости сохраняются в браузере; 0% отключает канал.
Файлы: public/music/{menu,forest,marsh,frost,ash,crypt,boss}.mp3.
