# Runes & Ramparts (R&R)

Браузерная фэнтезийная Tower Defense без Godot, серверной зависимости и монетизации.
Текущая версия v0.3.0: кампания из пяти рубежей.

- Свободное строительство вне дороги и препятствий, восемь башен, пять уровней и две специализации на третьем уровне.
- 15 типов противников, включая четыре вида боссов; 81 волна на пяти картах.
- Пиксельная графика, 64 варианта башен с разными силуэтами, отдельные эффекты оружия, оригинальные спрайты противников с покадровой анимацией, частицы, снаряды, индикаторы урона и статусов.
- Оригинальная синтезированная чиптюн-музыка и локальные однокристальные PT3 (AY через WASM и Web Worker) и звуковые эффекты с независимыми переключателями. Звук запускается после взаимодействия с браузером.
- Пауза, скорости ×1/×2/×4, приоритеты целей, продажа, разведка волн, полноэкранный режим.
- Локальный рейтинг, автосохранение незавершённой игры (IndexedDB, резерв localStorage), импорт/экспорт JSON. При восстановлении активной волны игра на паузе.
- TypeScript, PixiJS, Vite; игровая симуляция отделена от графики.

## Запуск

Node.js 22+.

    npm ci
    npm run dev

Или Docker Compose:

    docker compose up -d --build

Откройте http://localhost:8080 для Docker; Vite выведет собственный адрес.

## Проверки

    npm test
    npm run build

## Управление

Выберите башню в нижней панели или клавишами 1–6, затем свободное место на карте.
Клик по построенной башне — улучшение, выбор цели или продажа. ESC или ПКМ — отмена выбора. Пробел — пауза.
Строить можно и во время волны. Все данные сохраняются в текущем браузере и origin.

## Изменения 0.2.0

Ветки башен обладают отдельными механиками. Уровни 4–5 продолжают выбранную ветку. Составные волны перемешиваются, поздние враги прочнее, боссы устойчивее к замедлению. Старые сохранения читаются без сброса, но действуют новые правила баланса.

## Кампания 0.3.0

Пять карт (12/15/16/18/20 волн), последовательное открытие, звёзды за победы
(1–7 жизней: 1 звезда, 8–15: 2, 16–20: 3), по одному очку развития за звезду.
Рекорды по картам. Старые победы засчитываются за лесной рубеж.
Глобальные улучшения применяются при начале нового боя.
Казармы, молнии, три активных заклинания; ранний вызов следующей волны
после выхода всех врагов текущей волны приносит золото, но волны перекрываются.
PT3 можно открыть через «Звук», файл не передаётся на сервер и действует до перезагрузки.
Поддерживается обычный однокристальный PT3 до 64 КБ; TurboSound пока не поддерживается.
Исходники и лицензии проигрывателя/эмулятора: vendor/pt3, готовый WASM: public/audio.
Оригинальная музыка остаётся доступной.
